# Eventra - Event Management Portal

Eventra is a responsive event management web application for discovering, creating, managing, and registering for events.

## Features

- Browse and discover upcoming events
- Search and filter events
- View detailed event information
- Register for events
- Manage event registrations
- Create and manage events
- User profile and event dashboard
- Responsive interface
- Local data persistence

## Technologies Used

- React
- TypeScript
- Vite
- HTML
- CSS
